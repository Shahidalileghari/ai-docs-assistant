# 12 — Advanced features

Possible extensions:
- OCR and layout-aware parsing for scanned PDFs;
- table extraction with row/column context;
- multilingual embeddings and language-aware retrieval;
- hybrid search and reranking;
- knowledge graphs for entity relationships;
- document comparison and change detection;
- citations to PDF page coordinates;
- multimodal retrieval for diagrams and images;
- agentic workflows for approved actions.

Keep agent tools narrow, permissioned, auditable, and human-approved for consequential actions. An assistant that answers questions does not automatically need an autonomous agent.
