# 11 — Production and observability

Use durable object storage for originals, relational metadata, vector/lexical indexes, and a queue for ingestion jobs. Make ingestion idempotent and versioned.

Observe stage-level latency, parser failures, queue age, retrieval scores, citation rates, abstention rate, token usage, provider errors, and cost per successful answer. Avoid logging raw document content by default.

Deploy with secrets management, TLS, backups, migrations, health checks, autoscaling limits, and disaster-recovery tests.
