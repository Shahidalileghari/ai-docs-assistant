# Production-readiness checklist

- [ ] Authentication and tenant-aware authorization on every route.
- [ ] Document ACL filters enforced before retrieval.
- [ ] Private object storage and encryption at rest.
- [ ] Malware scanning and sandboxed parsers.
- [ ] File/page/token limits and quotas.
- [ ] Durable, idempotent background ingestion.
- [ ] Versioned parsing, chunking, and embedding pipeline.
- [ ] Citation validation and abstention evaluation.
- [ ] Prompt injection threat tests.
- [ ] Retention, export, and verified deletion workflow.
- [ ] Structured logs without raw document content by default.
- [ ] Traces and metrics for every pipeline stage.
- [ ] Backups, restore tests, migrations, and incident runbooks.
- [ ] Provider timeouts, retries, cost budgets, and fallback behavior.
- [ ] Privacy/legal review for the document types and jurisdictions involved.
